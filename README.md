📘 Project Overview

This repository currently includes two major task groups:

1. HTML Basic Tasks (html_basic/)

This folder contains introductory HTML exercises focused on writing clean, valid, well-structured HTML.

✔ base_index.html

The task requirements included:

File must be named base_index.html

Must contain:

<!DOCTYPE html>

<html lang="en">

A valid <head> section with:

<meta charset="UTF-8">

<title>

A <body> section with simple content

File must pass the W3C HTML Validator

No external libraries allowed

All code must be fully standards-compliant

This file was validated and corrected until the W3C validator confirmed it was valid.
